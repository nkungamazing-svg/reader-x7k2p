# คลังบทแปลส่วนตัว (PWA)

เว็บแอปนี้เก็บบทแปลและค่าการอ่านไว้ใน IndexedDB ของเบราว์เซอร์ ไม่มี API key และไม่มีโค้ดอัปโหลดบทแปลไปยังบริการภายนอก รูปจากเว็บต้นทางโหลดได้เมื่อเปิดสวิตช์ **โหลดรูปจากเว็บต้นทาง** (ค่าเริ่มต้นเปิด) จึงต้องมีอินเทอร์เน็ต และเบราว์เซอร์จะเรียกรูปจากเว็บต้นทางโดยตรงโดยไม่ส่ง referrer; เมื่อปิดสวิตช์ รูปภายนอกจะไม่ถูกโหลด ส่วนรูปที่ฝังเป็น data:image ในไฟล์สำรองยังแสดงได้ หากโหลดรูปไม่สำเร็จจะแสดงปุ่ม **ลองใหม่**

## ติดตั้งบน iPhone

1. โฮสต์ไฟล์ชุดนี้ผ่าน HTTPS
2. เปิด URL ใน Safari แล้วกดปุ่มแชร์ → **เพิ่มไปยังหน้าจอโฮม**
3. เปิดแอปจากไอคอน แล้วเลือก **นำเข้าไฟล์สำรอง**
4. เลือกไฟล์ JSON ที่ได้จากปุ่ม **สำรอง/ย้ายข้อมูล** ของส่วนขยาย แล้วเลือก **รวมกับข้อมูลเดิม** หรือ **แทนที่บทและตารางคำอ่าน**

หลังเปิดครั้งแรก ให้รอให้เว็บโหลดครบก่อนใช้งานออฟไลน์ ไฟล์แอป สไตล์ สคริปต์ ไอคอน และฟอนต์จะถูกเก็บใน Cache Storage; บทแปลและตารางคำอ่านจะอยู่ใน IndexedDB บนอุปกรณ์นั้น

## GitHub Pages

เพื่อไม่เผยไฟล์ของส่วนขยาย ให้สร้าง repository แยกที่มีเฉพาะเนื้อหาในโฟลเดอร์ `mobile-reader/` (วาง `index.html`, `app.js` และไฟล์ประกอบไว้ที่ root ของ repository) จากนั้นเปิด **Settings → Pages → Build and deployment**, เลือก **Deploy from a branch**, เลือก `main` และ `/(root)`, แล้วกด **Save**. เปิด URL HTTPS ที่ Pages แสดงใน Safari.

ถ้าเก็บ PWA ไว้ใน repository อื่นใต้ path `mobile-reader/`, ต้องตั้ง workflow ให้ deploy เนื้อหาในโฟลเดอร์นี้เป็น artifact ของ Pages; การเลือก `/root` จาก branch จะไม่เผยแพร่โฟลเดอร์ย่อยโดยตรง

**ความเป็นส่วนตัว:** การตั้ง repository เป็น private ไม่ได้ทำให้ URL ของ GitHub Pages เป็นส่วนตัวโดยอัตโนมัติในแผนทั่วไป หน้า Pages อาจเปิดให้คนทั่วไปเข้าถึงได้ แม้ repository เป็น private ขึ้นอยู่กับแผนและการตั้งค่า Pages ดังนั้นแยก repository เฉพาะ PWA และอย่า commit ไฟล์สำรอง JSON หรือบทแปลลง GitHub ตรวจ setting ความเป็นส่วนตัวของ Pages ก่อนเผยแพร่

ดู [การตั้งค่าแหล่งเผยแพร่ GitHub Pages](https://docs.github.com/en/pages/getting-started-with-github-pages/configuring-a-publishing-source-for-your-github-pages-site) และ [การเปลี่ยนการมองเห็นของ GitHub Pages](https://docs.github.com/en/enterprise-cloud@latest/pages/getting-started-with-github-pages/changing-the-visibility-of-your-github-pages-site)

## โหมดอ่านแบบพลิกหน้า

ค่าเริ่มต้นคือโหมดเลื่อนต่อเนื่องเหมือนเดิม และกดปุ่ม 📄/📜 ที่แถบล่างเพื่อสลับเป็นโหมดพลิกหน้าได้ทุกเมื่อ ในโหมดพลิกหน้า: แตะขอบซ้าย/ขวาของจอหรือปัดเพื่อเปลี่ยนหน้า แตะกลางจอเพื่อซ่อนหรือเปิดแถบเครื่องมือ และเมื่อพลิกเกินหน้าสุดท้ายของตอนระบบจะเปิดตอนถัดไปให้ทันที (ย้อนกลับจากหน้าแรกของตอนจะไปหน้าสุดท้ายของตอนก่อนหน้า) แถบด้านล่างแสดงเลขหน้าและเปอร์เซ็นต์ของตอน พร้อมเส้นความคืบหน้าบาง ๆ ที่ขอบบนจอ

ถ้าข้อความหรือแถบความคืบหน้าชนติ่งหรือกล้องหน้า (เช่น iPhone XR) ให้เพิ่ม **ระยะขอบบน (กันติ่ง/กล้อง)** ในหน้าตั้งค่า ระบบเว้น safe area ของจอไว้ให้อยู่แล้ว และสไลเดอร์นี้ใช้เผื่อเพิ่มได้อีกสูงสุด 90px

สลับเป็น **เลื่อนต่อเนื่อง** ได้ที่ *ตั้งค่าการอ่าน → โหมดการอ่าน* ซึ่งยังคงแตะย่อหน้าเพื่อเริ่มอ่านออกเสียงได้เหมือนเดิม ส่วนโหมดพลิกหน้าจะใช้การแตะจอสำหรับเปลี่ยนหน้าและซ่อนแถบแทน

## ฟอนต์และการแตะข้อความ

iPhone ไม่ยอมให้เว็บติดตั้งฟอนต์เพิ่มเองได้ แอปจึงฝังฟอนต์ SIL OFL มาด้วย (Noto Sans Thai, Sarabun, Noto Serif Thai และทางเลือก "ฟอนต์ระบบ iOS") แล้วให้เลือกที่ *ตั้งค่าการอ่าน → ฟอนต์ข้อความ* เปลี่ยนฟอนต์แล้วระบบจัดหน้าใหม่ให้และจำค่าไว้ ไฟล์สิทธิ์ฟอนต์อยู่ใน `fonts/OFL-*.txt`

ถ้าไม่อยากให้แตะย่อหน้าแล้วเริ่มอ่านออกเสียง ให้ปิดสวิตช์ **แตะข้อความเพื่ออ่านออกเสียง** ในหน้าตั้งค่า การแตะข้อความจะไม่มีผลอีก แต่ยังกดปุ่ม ▶ ที่แถบล่างเพื่ออ่านออกเสียงได้ตามเดิม (โหมดพลิกหน้าใช้การแตะจอสำหรับเปลี่ยนหน้าอยู่แล้ว)


## หน้าจอเปิดแอปและเวอร์ชัน

ทุกครั้งที่เปิดแอปจะเห็นหน้าจอเปิดพร้อมโลโก้ ชื่อแอป และเลขเวอร์ชัน (นิยามที่ `APP_VERSION` ใน `app.js`) แล้วเฟดเข้าสู่หน้าอ่านเองภายในประมาณหนึ่งวินาที ถ้าฐานข้อมูลหรือการนำเข้าไฟล์มีปัญหา หน้าจอนี้จะปิดให้เสมอ ไม่ค้างอยู่ เลขเวอร์ชันเดียวกันแสดงซ้ำที่ด้านล่างของหน้าตั้งค่าเพื่อใช้ตรวจว่าเครื่องที่ติดตั้งไว้ได้อัปเดตแล้วหรือยัง


## ซ่อนแถบเครื่องมือทั้งสองโหมด

ปุ่ม **⤢** บนแถบล่างซ่อนแถบหัวเรื่องและแถบเครื่องมือได้ทั้งโหมดเลื่อนต่อเนื่องและโหมดพลิกหน้า (อีกทางหนึ่งคือแตะกลางจอในโหมดพลิกหน้า) ระหว่างที่ซ่อนอยู่ การแตะจอหนึ่งครั้งจะเรียกแถบกลับมาโดยไม่กระตุ้นการอ่านออกเสียง และการปัดเพื่อเลื่อนอ่านยังทำงานปกติ ปุ่มเดิมจะเปลี่ยนเป็น **⤡** เมื่อแถบถูกซ่อน


## ธีมสำหรับอ่านนาน ๆ

นอกจาก มืด / สว่าง / ซีเปีย / ดำสนิท แล้ว มีธีมเพิ่มอีกสามแบบที่ออกแบบมาเพื่อการอ่านต่อเนื่อง: **🌿 ถนอมสายตา** (พื้นเขียวอ่อนแบบ eye-care ตัวอักษรเขียวเข้ม ลดความจ้า), **🌤️ ฟ้าเทา** (เทาโทนเย็น กลางวันสบายตา), และ **🌆 พลบค่ำ** (มืดอุ่น คอนทราสต์ต่ำกว่าโหมดดำสนิท อ่านก่อนนอนสบายกว่า) สีแถบสถานะของเบราว์เซอร์จะเปลี่ยนตามธีมด้วย ทุกธีมบันทึกค่าไว้ใน IndexedDB และมีผลทั้งโหมดเลื่อนและโหมดพลิกหน้า


## การจัดกลุ่มหน้าตั้งค่า

หน้าตั้งค่าแบ่งเป็น 5 กลุ่มการ์ด: **ตัวอักษร** (ฟอนต์, ขนาด, ระยะบรรทัด, ความกว้าง, ระยะขอบบน พร้อมกล่องตัวอย่างที่เปลี่ยนตามที่เลือกทันที), **ธีม**, **การอ่าน** (โหมด, ย่อหน้า, ไฮไลต์, เลื่อนตาม, แตะอ่าน), **เสียงอ่าน** (เสียง, ความเร็ว) และ **อื่น ๆ** (รูป, กันจอดับ) เพื่อให้ตัวเลือกที่เกี่ยวข้องกันอยู่ติดกันและหาได้เร็วขึ้น


## ขนาดรูปและอิโมจิในบท

รูปที่มีขนาดจริงเล็ก (ไม่เกิน 200×200 พิกเซล เช่น อิโมจิหรือสติกเกอร์จากเว็บต้นทาง) จะถูกแสดงขนาดเท่าตัวอักษร (~1.4em) แทนที่จะเป็นภาพประกอบเต็มหน้า ส่วนรูปใหญ่ยังแสดงเป็นภาพประกอบตามปกติ และถ้าบทแปลแนบ `font-size` ที่ใหญ่ผิดปกติมาในสไตล์ ระบบจะตัดค่านั้นทิ้งเพื่อไม่ให้ตัวอักษรหรืออิโมจิตัวเดียวกินพื้นที่ทั้งหน้า


## ทำไมอัปเดตถึงเร็วขึ้น

เดิม service worker เสิร์ฟไฟล์จาก cache ก่อนเสมอ ทำให้หลัง push แล้วมือถือยังเห็นโค้ดเก่าจนกว่า cache จะถูกแทนที่ ตอนนี้ไฟล์เปลือกแอป (`index.html`, `app.js`, `style.css`, manifest) ถูกดึงจากเครือข่ายก่อนและเก็บ cache ไว้ใช้ตอนออฟไลน์ ส่วนฟอนต์/ไอคอนยังใช้ cache ก่อนเพื่อประหยัดเน็ต แอปยังเรียกตรวจ service worker ใหม่ทุกครั้งที่กลับเข้าหน้าและทุก 5 นาทีระหว่างเปิดอยู่ ถ้ามีเวอร์ชันใหม่จะโหลดหน้าใหม่ให้ครั้งเดียวเอง (กันลูปด้วย sessionStorage) ส่วนเวลาที่ GitHub Pages ใช้ build ยังเป็นเรื่องของ GitHub ประมาณ 1–3 นาทีหลัง push และดูสถานะได้ที่แท็บ Actions ของ repository


## คำแนะนำการแตะจอในโหมดพลิกหน้า

ครั้งแรกที่เปิดโหมดพลิกหน้า แอปจะแสดงไกด์เรืองแสงที่ขอบซ้าย/ขวา (ปัดหรือแตะเพื่อเปลี่ยนหน้า) พร้อมป้ายกลางจอ "แตะกลางจอ · เปิด/ซ่อนเมนู" แล้วจางหายเองในราว 4 วินาที หรือหายทันทีเมื่อแตะครั้งแรก ทุกครั้งที่พลิกหน้าจะมีแสงวาบที่ขอบด้านที่เพิ่งพลิกเป็นสัญญาณว่ากดติด ปิดไกด์นี้ได้ที่ *ตั้งค่าการอ่าน → การอ่าน → แสดงคำแนะนำการแตะจอ*


## การนับเวอร์ชัน

ทุกครั้งที่มีการแก้ไข ไม่ว่าจะเป็นฟีเจอร์ การแก้บั๊ก หรือข้อความ จะอัปเลขเวอร์ชันก่อน commit เลขตัวท้าย (patch) วิ่ง 0 ถึง 9 แล้วจึงขึ้นเลขกลาง (minor): `1.4.0 … 1.4.9 → 1.5.0` ใช้คำสั่ง `python3 tools/bump-version.py patch` (หรือ `minor` / `major`) ซึ่งจะอัปเดต `APP_VERSION` ใน `app.js` และ `CACHE_NAME` ใน `service-worker.js` ไปพร้อมกัน จึงไม่มีทางที่สองไฟล์นี้หลุดจากกัน เลขเวอร์ชันแสดงบนหน้าจอเปิดแอปและท้ายหน้าตั้งค่าเพื่อให้ตรวจได้ว่าเครื่องที่ติดตั้งไว้เป็นรุ่นไหน รายละเอียดกติกาสำหรับผู้พัฒนาอยู่ใน `AGENTS.md`


## รายการบท (หน้าเลือกตอน)

แถวแต่ละตอนเป็นรูปแบบเดียวกันทั้งรายการ: ช่องเลขบทด้านซ้าย ชื่อเรื่องบรรทัดเดียว (ตัดคำเกินด้วย …) และป้ายสถานะด้านขวา ("อ่านแล้ว" หรือเปอร์เซ็นต์ที่อ่านค้างไว้) ตอนที่ยังไม่อ่านไม่มีป้ายเพื่อให้รายการดูโล่ง แถบความคืบหน้าแบบบางอยู่ที่ขอบล่างของแถวและแสดงเฉพาะตอนที่อ่านค้างไว้ หัวข้อ Novel และหัวข้อ Arc ติดอยู่ด้านบนขณะเลื่อนรายการ และมีจำนวนตอน/จำนวนที่อ่านแล้วกำกับ เมื่อเปิดรายการแอปจะเลื่อนไปที่ตอนที่กำลังอ่านให้อัตโนมัติ จึงไม่ต้องไล่หาด้วยมือในคลังที่มีหลายสิบตอน


## รูปตัวละคร (แตะชื่อเพื่อดูรูป)

ชื่อตัวละครที่ส่วนขยายทำเครื่องหมายไว้ (ขีดเส้นใต้จุด ๆ ในบท) กดแตะได้บนมือถือ แตะแล้วจะมีการ์ดเล็ก ๆ ขึ้นจากด้านล่างพร้อมรูปของตัวละครนั้น ดึงรูปจาก Re:Zero Wiki ด้วยชื่อภาษาอังกฤษที่แนบมากับชื่อ (ถ้าไม่มีชื่อภาษาอังกฤษจะแจ้งว่าไม่พบ) รูปที่เคยเปิดแล้วจะถูกจำไว้ในเครื่องและแสดงได้ทันทีโดยไม่ต้องต่อเน็ต การดึงรูปทำงานผ่านสวิตช์ **โหลดรูปจากเว็บต้นทาง** เช่นเดียวกับรูปในบท ปิดสวิตช์นี้แล้วจะไม่มีการเรียกออกเน็ตเลย และการ์ดจะหายไปเองใน 10 วินาทีหรือปิดด้วยปุ่ม ×


### ถ้าขึ้นว่าไม่พบชื่อทุกตัว

ถ้าไฟล์บทมีแต่ชื่อไทยและไม่มีชื่อภาษาอังกฤษ การ์ดจะเปิดช่องให้ตั้งชื่อครั้งแรก: พิมพ์ชื่อในวิกิ (เช่น `Otto Suwen`) หรือพิมพ์บางส่วนแล้วเลือกจากรายการที่ระบบค้นให้ (กดที่ชื่อแล้วระบบจะดึงรูปและจำคู่ชื่อไทย–อังกฤษไว้) ครั้งต่อไปแตะชื่อเดิมจะขึ้นรูปทันทีโดยไม่ต้องตั้งซ้ำ ข้อมูลคู่นี้เก็บใน IndexedDB ของเครื่อง


## นำเข้าตารางชื่อตัวละคร (กลอสซารี)

ถ้ามีไฟล์กลอสซารีของส่วนขยาย (รายการ `{ "src": "Otto Suwen", "dest": "อ็อตโต้" }`) กด *ตั้งค่าการอ่าน → อื่น ๆ → ตารางชื่อตัวละคร → นำเข้า JSON* ระบบจะจับคู่ `dest` (ชื่อไทย) เข้ากับ `src` (ชื่ออังกฤษ) ให้ทุกคำ แล้วแตะชื่อในบทจะขึ้นรูปได้ทันทีโดยไม่ต้องตั้งทีละตัว รายการที่ชื่อมีวงเล็บอธิบาย เช่น `ซู-โบ้(ซุบารุ)` จะถูกจับคู่ทั้งแบบมีและไม่มีวงเล็บ ปุ่ม **ล้าง** จะลบตารางนี้ออก และจำนวนที่จับคู่ไว้จะแสดงใต้ปุ่ม


ในโหมดพลิกหน้า การแตะชื่อตัวละครจะเปิดการ์ดรูปแทนการพลิกหน้า (การปัดซ้าย/ขวายังเปลี่ยนหน้าได้ตามปกติ และแตะขอบจอนอกชื่อยังพลิกหน้าเหมือนเดิม)


## ปิดการเลือกข้อความในหน้าอ่าน

หน้าอ่านปิดการเลือกข้อความและการกดค้างเพื่อเรียกเมนูของ iOS ทั้งหมด (`user-select:none`, `-webkit-touch-callout:none`) จึงไม่มีแถบไฮไลต์สีฟ้าเวลากดค้าง เหลือเพียงการอ่าน การแตะย่อหน้าเพื่ออ่านออกเสียง และการแตะชื่อตัวละครเพื่อดูรูป ส่วนช่องกรอกในหน้าตั้งค่ายังพิมพ์และเลือกข้อความได้ตามปกติ
