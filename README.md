# คลังบทแปลส่วนตัว (PWA)

เว็บแอปนี้เก็บบทแปลและค่าการอ่านไว้ใน IndexedDB ของเบราว์เซอร์ ไม่มี API key และไม่มีโค้ดอัปโหลดบทแปลไปยังบริการภายนอก รูปจากเว็บต้นทางโหลดได้เมื่อเปิดสวิตช์ **โหลดรูปจากเว็บต้นทาง** (ค่าเริ่มต้นเปิด) จึงต้องมีอินเทอร์เน็ต และเบราว์เซอร์จะเรียกรูปจากเว็บต้นทางโดยตรงโดยไม่ส่ง referrer; เมื่อปิดสวิตช์ รูปภายนอกจะไม่ถูกโหลด ส่วนรูปที่ฝังเป็น data:image ในไฟล์สำรองยังแสดงได้ หากโหลดรูปไม่สำเร็จจะแสดงปุ่ม **ลองใหม่**

## ติดตั้งบน iPhone

1. โฮสต์ไฟล์ชุดนี้ผ่าน HTTPS
2. เปิด URL ใน Safari แล้วกดปุ่มแชร์ → **เพิ่มไปยังหน้าจอโฮม**
3. เปิดแอปจากไอคอน แล้วเลือก **นำเข้าไฟล์สำรอง**
4. เลือกไฟล์ JSON ที่ได้จากปุ่ม **สำรอง/ย้ายข้อมูล** ของส่วนขยาย แล้วเลือก **รวมกับข้อมูลเดิม** หรือ **แทนที่บทและตารางคำอ่าน**

หลังเปิดครั้งแรก ให้รอให้เว็บโหลดครบก่อนใช้งานออฟไลน์ ไฟล์แอป สไตล์ สคริปต์ ไอคอน และฟอนต์จะถูกเก็บใน Cache Storage; บทแปลและตารางคำอ่านจะอยู่ใน IndexedDB บนอุปกรณ์นั้น

## GitHub Pages

เพื่อไม่เผยไฟล์ของส่วนขยาย ให้สร้าง repository แยกที่มีเฉพาะเนื้อหาในโฟลเดอร์ `mobile-reader/` (วาง `index.html`, `app.js` และไฟล์ประกอบไว้ที่ root ของ repository) จากนั้นเปิด **Settings → Pages → Build and deployment**, เลือก **Deploy from a branch**, เลือก `main` และ `/(root)`, แล้วกด **Save**. เปิด URL HTTPS ที่ Pages แสดงใน Safari.

ถ้าเก็บ PWA ไว้ใน repository อื่นใต้ path `mobile-reader/`, ต้องตั้ง workflow ให้ deploy เนื้อหาในโฟลเดอร์นี้เป็น artifact ของ Pages; การเลือก `/root` จาก branch จะไม่เผยแพร่โฟลเดอร์ย่อยโดยตรง

**ความเป็นส่วนตัว:** การตั้ง repository เป็น private ไม่ได้ทำให้ URL ของ GitHub Pages เป็นส่วนตัวโดยอัตโนมัติในแผนทั่วไป หน้า Pages อาจเปิดให้คนทั่วไปเข้าถึงได้ แม้ repository เป็น private ขึ้นอยู่กับแผนและการตั้งค่า Pages ดังนั้นแยก repository เฉพาะ PWA และอย่า commit ไฟล์สำรอง JSON หรือบทแปลลง GitHub ตรวจ setting ความเป็นส่วนตัวของ Pages ก่อนเผยแพร่

ดู [การตั้งค่าแหล่งเผยแพร่ GitHub Pages](https://docs.github.com/en/pages/getting-started-with-github-pages/configuring-a-publishing-source-for-your-github-pages-site) และ [การเปลี่ยนการมองเห็นของ GitHub Pages](https://docs.github.com/en/enterprise-cloud@latest/pages/getting-started-with-github-pages/changing-the-visibility-of-your-github-pages-site)

## โหมดอ่านแบบพลิกหน้า

ค่าเริ่มต้นคือโหมดเลื่อนต่อเนื่องเหมือนเดิม และกดปุ่ม 📄/📜 ที่แถบล่างเพื่อสลับเป็นโหมดพลิกหน้าได้ทุกเมื่อ ในโหมดพลิกหน้า: แตะขอบซ้าย/ขวาของจอหรือปัดเพื่อเปลี่ยนหน้า แตะกลางจอเพื่อซ่อนหรือเปิดแถบเครื่องมือ และเมื่อพลิกเกินหน้าสุดท้ายของตอนระบบจะเปิดตอนถัดไปให้ทันที (ย้อนกลับจากหน้าแรกของตอนจะไปหน้าสุดท้ายของตอนก่อนหน้า) แถบด้านล่างแสดงเลขหน้าและเปอร์เซ็นต์ของตอน พร้อมเส้นความคืบหน้าบาง ๆ ที่ขอบบนจอ

ถ้าข้อความหรือแถบความคืบหน้าชนติ่งหรือกล้องหน้า (เช่น iPhone XR) ให้เพิ่ม **ระยะขอบบน (กันติ่ง/กล้อง)** ในหน้าตั้งค่า ระบบเว้น safe area ของจอไว้ให้อยู่แล้ว และสไลเดอร์นี้ใช้เผื่อเพิ่มได้อีกสูงสุด 90px

สลับเป็น **เลื่อนต่อเนื่อง** ได้ที่ *ตั้งค่าการอ่าน → โหมดการอ่าน* ซึ่งยังคงแตะย่อหน้าเพื่อเริ่มอ่านออกเสียงได้เหมือนเดิม ส่วนโหมดพลิกหน้าจะใช้การแตะจอสำหรับเปลี่ยนหน้าและซ่อนแถบแทน

## ฟอนต์และการแตะข้อความ

iPhone ไม่ยอมให้เว็บติดตั้งฟอนต์เพิ่มเองได้ แอปจึงฝังฟอนต์ SIL OFL มาด้วย (Noto Sans Thai, Sarabun, Noto Serif Thai และทางเลือก "ฟอนต์ระบบ iOS") แล้วให้เลือกที่ *ตั้งค่าการอ่าน → ฟอนต์ข้อความ* เปลี่ยนฟอนต์แล้วระบบจัดหน้าใหม่ให้และจำค่าไว้ ไฟล์สิทธิ์ฟอนต์อยู่ใน `fonts/OFL-*.txt`

ถ้าไม่อยากให้แตะย่อหน้าแล้วเริ่มอ่านออกเสียง ให้ปิดสวิตช์ **แตะข้อความเพื่ออ่านออกเสียง** ในหน้าตั้งค่า การแตะข้อความจะไม่มีผลอีก แต่ยังกดปุ่ม ▶ ที่แถบล่างเพื่ออ่านออกเสียงได้ตามเดิม (โหมดพลิกหน้าใช้การแตะจอสำหรับเปลี่ยนหน้าอยู่แล้ว)
